# CSV2XL - 医療文書担当一覧アプリケーション

医療文書管理システム「Papyrus」からの CSV データを SQLite データベースに取り込み、医療文書の担当一覧を表示・編集する PyQt6 製のデスクトップアプリケーションです。以前の「医療文書担当一覧.xlsm」の機能(患者ID検索・並び替え・担当者名などの入力)をアプリだけで行えます。

## 主な機能

- 最新の CSV ファイルを自動検出して取り込み(既存の行と同じものは追加しない)
- 複数エンコーディング対応(Shift-JIS、CP932、UTF-8)
- 担当一覧の表示(既定は 預り日 → 診療科 → 患者ID の順。列見出しのクリックで並び替え)
- 担当者名(ドロップダウン)・医師依頼日(カレンダー)・備考の入力
- 行の手動追加・削除、表示中の一覧の CSV 出力
- 患者ID検索(見つかった行を順に表示)
- 複数の PC から同じデータベースを共有(5 秒ごとに他の端末の変更を反映)
- 取り込みのたびにデータベースのバックアップを作成
- 除外する文書名・医師名と担当者名のリストは、全端末で共有

## 前提条件

- **OS**: Windows 11
- **Python**: 3.13 以上

## インストール

[uv](https://docs.astral.sh/uv/) を使用します。仮想環境(`.venv`)も自動で作成されます。

```bash
git clone <repository-url>
cd CSV2XL
uv sync
uv run python main.py
```

## 使い方

### 基本的なワークフロー

1. Papyrus からダウンロードフォルダに CSV ファイルをエクスポート
2. 左パネルの **CSV取り込み** ボタンをクリック
   - 最新の CSV を読み込み、除外リストに該当する行を除いてデータベースに追加
   - 処理済み CSV を processed フォルダへ移動し、データベースのバックアップを作成
3. 追加した件数が表示され、右側の担当一覧に反映されます

### xlsm 取り込み

左パネルの **xlsm取り込み** で、xlsm フォルダにある `医療文書担当一覧_YYYYMMDDhhmm.xlsm` のうち、ファイル名の日時が最も新しいものを取り込みます。

- 預り日〜医師名(A〜F 列)が同じ行がデータベースにあるときは、行を追加しません。データベースで空欄の担当者名・医師依頼日・備考だけを xlsm の値で埋めます(入力済みの値は上書きしません。削除した行は戻りません)
- 日付が読めない行、医師依頼日が預り日より前の行、担当者名が担当者名のリストにない行は取り込まず、完了メッセージに行番号と理由を表示します

### バックアップ

起動時にその日のバックアップがなければ、バックアップフォルダに `医療文書担当一覧_YYYYMMDDhhmm.db` を作ります。CSV・xlsm の取り込み後にも作ります。保持日数(`[Backup] retention_days`)を過ぎたものは起動時に削除します。

### 担当一覧

起動すると、左に操作パネル、右に担当一覧を並べた画面が開きます(既定は最大化)。左パネルと一覧の境目をドラッグすると左パネルの幅を変えられ、次回もその幅で開きます。

- **患者ID検索**: 左パネルの入力欄に患者ID を入力して「検索」(または Enter)。「前へ」「次へ」で該当する行を移動し、「n/m件」で位置を表示します
- **並び替え**: 列見出しをクリックすると、その列で昇順・降順を切り替えます
- **入力**: 担当者名・医師依頼日・備考の列をダブルクリック(またはキー入力)で編集します。確定するとすぐに保存されます
  - 医師依頼日は ▼ で開くカレンダーから選ぶか、`2025/01/05` の形式で打ち込みます。消すときはセルを選んで Delete キーを押します
  - 他の端末が先に同じ行を更新していた場合は、警告を出して最新の内容を読み込みます
- **行の追加・削除**: 「行の追加」で預り日〜医師名を入力して1行追加します。「行の削除」は選んだ行を確認してから削除します(削除した行は、同じ CSV を取り込み直しても戻りません)
- **CSV出力**: 表示中の並び順のまま、画面と同じ列を CSV(BOM 付き UTF-8)に書き出します
- **自動更新**: 5 秒ごとに他の端末の変更を確認し、最新の内容を読み込みます

### 設定

| ボタン | 内容 | 保存先 |
|---|---|---|
| 除外項目: 文書名 / 医師名 | 取り込まない行の条件(部分一致) | データベース(全端末共通) |
| 担当者名 | 担当者名のドロップダウンの選択肢。「configから読み込み」で config.ini の `[Staff] ordered_names` を一括登録 | データベース(全端末共通) |
| 画面サイズ | アプリ全体のフォントサイズ(すぐに反映)、ウインドウサイズ、起動時に最大化するか | config.ini(端末ごと) |
| フォルダパス | ダウンロード・データベースファイル・バックアップ・xlsm の場所 | config.ini(端末ごと) |

## データベースの場所

既定は `C:\Shinseikai\CSV2XL\医療文書担当一覧.db` です。共有フォルダに移す場合は、ファイルをコピーしてから各 PC の「フォルダの場所」で「データベースファイル」を変更してください。

## 設定ファイル(config.ini)

exe で実行する場合は、exe と同じフォルダの `config.ini` を読み書きします(初回起動時に同梱版がコピーされます)。

```ini
[Appearance]
font_size = 11
window_width = 350
window_height = 330

[Paths]
downloads_path = C:\Users\...\Downloads
database_path = C:\Shinseikai\CSV2XL\医療文書担当一覧.db
backup_path = C:\Shinseikai\CSV2XL\backup
processed_path = C:\Shinseikai\CSV2XL\processed

[Backup]
retention_days = 14
```

- **Paths**: ファイル・フォルダのパス
- **Backup**: バックアップ・処理済み CSV の保持期間(日数)
- **ExcludeDocs / ExcludeDoctors**: 移行スクリプトが読むだけです。移行後はデータベースのリストを使います

```

```

## トラブルシューティング

**CSV ファイルが見つからない**
- 「フォルダの場所」のダウンロードフォルダが正しいか確認
- ファイル名が `XXXX_YYYYMMDDhhmmss.csv` 形式か確認

**データベースを開けない / 保存に失敗する**
- 「フォルダの場所」のデータベースファイルのパスと、共有フォルダへのアクセス権を確認
- 「database is locked」と表示された場合は、他の端末の処理が終わってから再度操作

**データベースが壊れた**
- バックアップフォルダの `医療文書担当一覧_YYYYMMDDhhmm.db` をデータベースファイルの場所にコピーして戻す
