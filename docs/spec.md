# 仕様書(C# 版への移植用)

Python 版の動作を言語に依存しない形でまとめる。C# 版はこの仕様と `tests/` のテストケースに合わせる。

## データベース

- SQLite。スキーマは `services/schema.sql`(C# 版でもこのファイルをそのまま使う)。
- スキーマの版は `PRAGMA user_version` で管理する(現在 2)。0 なら `schema.sql` を実行する。
- 版 1 → 2 の移行: `BEGIN IMMEDIATE` でロックを取り、版がまだ 1 なら `ALTER TABLE documents ADD COLUMN deleted INTEGER NOT NULL DEFAULT 0` と `PRAGMA user_version = 2` を実行してコミットする(複数の端末が同時に開いても二重に追加しない)。
- 共有ファイルサーバーに置くため、次の設定で使う。
  - `PRAGMA journal_mode=DELETE`(WAL はネットワーク越しでは使えない)
  - ロック待ちは 5 秒(`busy_timeout`)
  - 書き込みは短いトランザクションで行い、開いたまま待たない
- 型
  - 日付: `TEXT` の `YYYY-MM-DD`(C# では `DateOnly`)
  - 日時: `TEXT` の `YYYY-MM-DDThh:mm:ss`
  - 患者ID: `INTEGER`(C# では `long`)

### documents(担当一覧)

| 列 | 画面の見出し | 編集 |
|---|---|---|
| received_date | 預り日 | 不可 |
| patient_id | 患者ID | 不可 |
| patient_name | 患者氏名 | 不可 |
| document_name | 文書名 | 不可 |
| department | 診療科 | 不可 |
| doctor_name | 医師名 | 不可 |
| staff_name | 担当者名 | ドロップダウン(担当者リスト+空欄。入力済みの値がリストに無ければ、その値も選択肢に残す) |
| requested_date | 医師依頼日 | 日付欄(▼でカレンダー、`YYYY/MM/DD` の打ち込みも可)。空欄から開くと今日の日付。カレンダーで日付をクリックするとすぐ保存。セルを選んで(編集中も) Delete キーで消去 |
| note | 備考 | 自由入力(前後の空白は除く。空欄は NULL) |

- 一覧の文字の配置: 患者氏名・文書名・備考は左寄せ、ほかの列は中央。日付は `YYYY/MM/DD` で表示する。

- 編集はセルを確定した時点で保存する。
- 楽観ロック: `UPDATE … SET …, version = version + 1 WHERE id = ? AND version = ?`。更新件数が 0 なら他の端末が先に更新しているので、「他の端末でこの行が更新されたため、{保存 / 削除}できませんでした。\n最新の内容を読み込みます。」を表示して読み直す。
- 削除は論理削除: `UPDATE … SET deleted = 1, version = version + 1 WHERE id = ? AND version = ? AND deleted = 0`(楽観ロックは更新と同じ)。一覧には `deleted = 0` の行だけを表示する。CSV 取り込みの重複チェックには削除済みの行も含めるため、同じ CSV を取り込み直しても削除した行は戻らない。
- 手動の追加: 預り日(日付欄。既定は今日)〜医師名をすべて入力して1行追加する(重複チェックはしない)。未入力の項目があるか患者IDが数字でなければ「すべての項目を入力してください。\n患者IDは数字で入力してください。」。追加した行を選び、一覧の中央に表示する。

### list_items(全端末で共有するリスト)

| category | 内容 |
|---|---|
| `staff` | 担当者名 |
| `exclude_doc` | 取り込まない文書名(部分一致) |
| `exclude_doctor` | 取り込まない医師名(部分一致) |

`sort_order` の順に表示する。保存するときはカテゴリごとに全件を置き換える(空白は除き、重複は1つにする)。

## CSV の取り込み

1. ダウンロード・バックアップ・処理済みフォルダが無ければ作る。処理済みフォルダの CSV のうち、更新日時から保持日数(`[Backup] retention_days`)以上たったものを削除する。
2. ダウンロードフォルダから `XXXXX_YYYYMMDDhhmmss.csv`(`_` の前は 0〜5 文字、後は 14 文字)のうち、更新日時が最も新しいファイルを選ぶ。無ければ「ダウンロードフォルダにCSVファイルが見つかりません。」。
3. Shift-JIS → CP932 → UTF-8 の順に読めるまで試す。先頭 3 行を飛ばし、4 行目をヘッダーにする。どれでも読めなければ「CSVファイルの読み込みに失敗しました。」。
4. 文書名(元の 7 列目)と医師名(元の 10 列目)から、半角・全角の空白と `*` を除く。
5. 除外リストの文字列を含む行を除く(文書名と医師名、それぞれ部分一致)。
6. 元の 1〜3・9・11 列目を捨てる。残りの列が、預り日・患者ID・患者名・文書名・診療科・医師名になる。
7. 預り日 `YYYYMMDD` を `YYYY-MM-DD` にする。
8. 書き込みロック(`BEGIN IMMEDIATE`)を取ってから、既存行と A〜F 列(預り日〜医師名)がすべて同じ行を除いて追加する。同じ CSV 内の重複は除かない。実データに A〜F 列が同じ行があるため、UNIQUE 制約は使わない。
9. CSV を処理済みフォルダへ移動し、DB をバックアップする(SQLite の backup API で `医療文書担当一覧_YYYYMMDDhhmm.db`)。
10. 「{追加件数}件を追加しました。」を表示して一覧を読み直す。

## xlsm の取り込み

1. xlsm フォルダ(`[Paths] xlsm_path`)の `医療文書担当一覧_YYYYMMDDhhmm.xlsm` のうち、ファイル名の日時が最も新しいものを選ぶ。無ければ「{フォルダ} に医療文書担当一覧_年月日時分.xlsm が見つかりません。」。
2. アクティブなシートの 1 行目を見出しにし、見出し名で列を探す(列の順番は問わない)。必要な列: 預り日・患者ID・患者名・文書名・診療科・医師名・担当者名・医師依頼日・備考。足りなければ「{ファイル名} に列がありません: {列名}」。
3. 9 列すべてが空の行は飛ばす。文字列は前後の空白を除き、空なら NULL にする。
4. 日付は日付型・Excel のシリアル値・`YYYY/MM/DD`(`YYYY-MM-DD`、後ろに時刻があってもよい)を読む。患者ID は `,` を除いた数字。
5. 次の行は取り込まず、「n行目: 理由」を完了メッセージに出す(最大 50 行)。
   - 預り日が空 / 日付でない、患者IDが数値でない、医師依頼日が日付でない、医師依頼日が預り日より前、担当者名が担当者名のリスト(`list_items` の staff)にない
6. `BEGIN IMMEDIATE` で書き込みロックを取り、既存行(削除済みを含む)と A〜F 列で突き合わせる。A〜F 列が同じ行は id の順に xlsm の行と 1 対 1 で対応させる。
   - 対応する既存行が無い: 担当者名・医師依頼日・備考を含めて追加する。
   - 対応する既存行がある: 既存行で NULL の担当者名・医師依頼日・備考だけを xlsm の値で埋める(`version` を 1 増やす)。入力済みの値は上書きしない。削除済みの行は変えない。
7. DB をバックアップし、「{ファイル名}\n{追加}件を追加し、{埋めた行数}件の空欄を埋めました。」を表示して一覧を読み直す。

## バックアップ

- 起動時に DB へ接続できたら、バックアップフォルダに当日の `医療文書担当一覧_YYYYMMDD*.db` が無いときだけバックアップを作る(CSV・xlsm 取り込み後のバックアップと同じ形式)。失敗したら警告を表示して起動は続ける。
- 起動時に、更新日時から保持日数(`[Backup] retention_days`)以上たったバックアップを削除する。

## 一覧画面

- 1つのウィンドウの左に操作パネル、右に担当一覧を置く。起動時に DB へ接続して一覧を表示する(接続できなければエラーを表示し、一覧は空のまま)。
- ウィンドウの位置と大きさ: 終了時の位置・大きさ(最大化していたら、最大化を解除したときのもの)と最大化の状態を保存し、次回はそれで開く。初回は `[Appearance] window_width` / `window_height` の大きさで開く。保存した位置(左上)がどの画面にも入らなければ、大きさだけを戻す。
- フォントサイズは `[Appearance] font_size` に保存し、設定ダイアログの「フォントサイズ」で変える(6〜24 の整数。範囲外や数字以外は「フォントサイズは 6〜24 の数字で入力してください。」)。OK ですぐに反映する。アプリ全体(一覧・左パネル・ダイアログ)に使い、一覧の行の高さを文字の高さ + 8px にする。
- 一覧の左端の行番号(表示中の行の上から 1, 2, 3…)の見出しは「番号」。
- 列幅: 終了時(とフォルダパスの変更で一覧を作り直すとき)に各列の幅を `[Appearance] column_widths`(カンマ区切り)に保存し、次回もその幅で開く。保存した値の列数が一覧の列数と違えば既定の幅を使う。
- 左パネルと一覧の境目はドラッグで動かせる。終了時の左パネルの幅を保存し、次回もその幅で開く(左パネルの最小幅より狭くはならない)。
- タイトル(医療文書担当一覧 vX.Y.Z)はタイトルバーだけに表示する。
- 左パネルは一覧の備考列まで横スクロールなしで見えるよう、ボタンの文字の幅まで狭くできる(Windows の既定のボタンの最小幅 約80px は使わない)。
- 左パネルの並び: 患者ID検索(入力欄と検索 / 絞り込み解除 / 結果の件数) / Papyrus: CSV取り込み / データ: 行の追加・行の削除 / 除外項目: 文書名・医師名 / 設定 / 閉じる。
- 設定: xlsm取り込み・CSV出力・フォルダパス・フォントサイズ・担当者名・閉じるのボタンを並べたダイアログを開く。ボタンを押すとダイアログを閉じてから、その処理を行う。
- 行の削除: Ctrl+クリック(1行ずつ追加)・Shift+クリック(範囲)で複数行を選べる。「次の n 行を削除しますか?」の下に選んだ行の患者ID・患者氏名・文書名を先頭 10 行まで(それより多ければ「ほか n 件」)表示して確認してから削除する。未選択なら「削除する行を選んでください。」。複数行は1つのトランザクションで削除し、1行でも他の端末で更新されていたら1行も削除せず競合の警告を出す。
- CSV出力: 画面と同じ 9 列(日本語の見出し)を、フィルタで表示中の行だけ、画面の並び順・表示形式のまま BOM 付き UTF-8 で書き出す。保存先はダイアログで選ぶ(既定はダウンロードフォルダの `医療文書担当一覧_YYYYMMDDhhmm.csv`)。
- 担当者名・除外する文書名・除外する医師名: ダイアログの「configから読み込み」で、一覧をそれぞれ config.ini の `[Staff] ordered_names`・`[ExcludeDocs] list`・`[ExcludeDoctors] list`(カンマ区切り)に置き換える(OK で DB に保存)。config のリストが空なら「config.ini の {キー} に{項目名}がありません。」と警告する。
- 行の詳細: 行をダブルクリックすると、預り日〜医師名を全文(折り返し、選んでコピーできる)で表示し、担当者名(ドロップダウン)・医師依頼日(日付欄と「未設定」)・備考を編集するダイアログを開く。OK で変更があれば保存する(楽観ロックはセルの編集と同じ)。セルの直接編集は F2 キーか文字の入力で始める(ダブルクリックでは始めない)。担当者名・医師依頼日・備考のセルは左クリックでも、そのセルだけの編集を始める(担当者名はすぐにドロップダウンを開く。Ctrl/Shift+クリックは行の選択なので編集を始めない)。このため、これらのセルのダブルクリックでは詳細ダイアログは開かない。
- セルを右クリックすると「コピー」メニューを出し、そのセルの表示文字をクリップボードに入れる。
- 列のフィルタ: 列見出しを右クリックすると、その列の値(ほかの列のフィルタで残る行の値。並びは並べ替えと同じで空欄は「(空白)」として末尾)をチェックボックスで選ぶダイアログを開く。「すべて選択」でまとめて切り替える。1つもチェックしなければ「表示する値を1つ以上選んでください。」と警告する。
  - 患者氏名・文書名・医師名・担当者名・備考は「含む文字」も入力でき、その文字を含む行(部分一致)に絞り込む。
  - 預り日・医師依頼日は「開始日」「終了日」(それぞれ「指定しない」を選べる)で日付の範囲に絞り込む。範囲を指定すると、その列が空欄の行は表示しない。開始日が終了日より後なら「開始日は終了日以前の日付にしてください。」と警告する。
  - 条件はすべて満たす行を表示する(チェックボックス・含む文字・日付の範囲、ほかの列のフィルタ、患者ID検索の AND)。すべてチェックで含む文字・日付の範囲も無ければ、その列のフィルタを外す。
  - フィルタをかけた列は見出しに「▼」を付ける。フィルタは並べ替え・読み直しの後も保つ。編集した値がフィルタに合わなくなっても、読み直すまで行は残す。
- フォルダパス: ダウンロードフォルダ・データベースファイル・バックアップフォルダ・xlsm フォルダを、それぞれ「参照...」(データベースファイルは存在しないファイル名も選べる)と「開く」(無ければ「指定されたフォルダが存在しません。」)付きで編集する。処理済みフォルダは config.ini でだけ変える。OK で保存したら、DB に接続し直して一覧を作り直す。
- 既定の並び: 預り日 → 診療科 → 患者ID の昇順(同じ値なら登録順)。開いたときは末尾(最新)の行を表示する。
- 列見出しをクリックすると、その列で昇順と降順を切り替える。空欄の行は、昇順でも降順でも末尾に置く。
- 患者ID検索: 完全一致(全角の数字も半角にして読む。行の追加の患者IDも同じ)。その患者IDの行だけを表示し(列のフィルタも併せて効く)、先頭の行を選んで「患者ID {ID}: n件」を表示する。絞り込みは並べ替え・読み直しの後も保ち、件数も表示し直す。「絞り込み解除」か、検索欄を空にして検索すると全件の表示に戻す(「絞り込み解除」は検索欄も空にする)。
  - 数字以外: 「数値を入力してください。」
  - 0 件(列のフィルタで隠れている行も含めて表示する行が無い): 「該当する患者IDは見つかりませんでした。」直前の絞り込みはそのまま。
- 自動更新: 5 秒ごとに `PRAGMA data_version` を確認し、他の端末の変更があれば読み直す(編集中は待つ)。

## 端末ごとの設定(config.ini)

`[Paths]`(downloads_path, database_path, backup_path, processed_path, xlsm_path)、`[Appearance]`(font_size, window_x, window_y, window_width, window_height, start_maximized(終了時に最大化していたか), side_panel_width, column_widths)、`[Backup] retention_days`、`[DialogSize]`、`[Staff] ordered_names`・`[ExcludeDocs] list`・`[ExcludeDoctors] list`(担当者名・除外する文書名・除外する医師名を一括登録するためのカンマ区切りのリスト)。
